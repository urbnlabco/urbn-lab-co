# URBN LAB Co

Premium sneakers and streetwear.

## Website

URBN LAB Co is an online retail project designed for customers in Thailand and international markets.

## Brand Direction

- Premium urban aesthetic
- Black, white and lime accent
- Mobile-friendly design
- Sneakers at launch
- Streetwear and accessories planned for future expansion

## Website Files

- `index.html` — Homepage
- `styles.css` — Stylesheet
- `script.js` — JavaScript functionality

## Hosting

The website is intended for deployment using Cloudflare Pages.

## Development Status

Initial website foundation. Ecommerce checkout, payment processing, inventory management and fulfilment integrations remain to be implemented and tested.
